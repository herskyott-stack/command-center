# tasks/inbox/

New voice commands land here as Markdown task files.

**Lifecycle:** Jake speaks → Orion writes a task file here (e.g. `2026-09-21-140500-update-dj-site-headline.md`) → Orion picks it up → moves it to `../active/` while executing → moves it to `../done/` when finished.

A task file contains: what was asked (Jake's words), the plan, and links to the `runs/` entries it produced. Nothing is ever deleted — finished tasks live in `done/` forever as the audit trail.
